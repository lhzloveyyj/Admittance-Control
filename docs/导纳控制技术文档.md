# 手持除螨仪导纳控制 —— 技术文档

## 1. 项目概述

### 1.1 应用场景

手持除螨仪加装**水平力传感器**和**无刷电机助力轮**，用户在推拉设备时，电机自动提供助力，使力传感器读数趋近于零，实现"**零阻力**"手感。

```
        ┌──────────┐      ┌──────────┐      ┌──────────┐
 用户 ──│ 手柄     │──────│ 力传感器 │──────│ 机身     │── 地面
 推拉   │ (m₁)    │  F   │          │      │ (m₂)     │
        └──────────┘      └──────────┘      └────┬─────┘
                                                 │
                                            ┌────▼────┐
                                            │ 助力轮   │
                                            │ (无刷电机)│
                                            └─────────┘
```

### 1.2 控制目标

| 目标 | 含义 |
|---|---|
| `F_sensor → 0` | 力传感器读数稳定在零 |
| 零阻力手感 | 用户推拉时感觉不到水平方向的阻力 |
| 平稳无振荡 | 电机助力平滑，无抖动、无超调 |

## 2. 物理模型

### 2.1 一维两体模型

设备简化为手柄（$m_1$）和机身（$m_2$）两个质量块，力传感器位于两者之间：

$$F_{sensor} = F_{human} - F_{motor} \tag{1}$$

- $F_{human}$：用户施加在手柄上的水平推力（向前为正）
- $F_{motor}$：电机通过助力轮施加在地面上的水平力
- $F_{sensor}$：力传感器的读数（手柄与机身间相互作用力）

### 2.2 符号约定

| 符号 | 含义 | 正方向 |
|---|---|---|
| $F_{human}$ | 用户推力 | 向前推 = + |
| $F_{motor}$ | 电机助力 | 向前驱动 = + |
| $F_{sensor}$ | 传感器读数 | 拉伸 = + |
| $v$ | 设备速度 | 向前 = + |

传感器受拉（用户前推、电机滞后）→ $F_{sensor} > 0$ → 电机应加速前进。

## 3. 控制架构

### 3.1 三层级联结构

```
┌────────────────────────────────────────────────────────────┐
│                      AT32 MCU                              │
│                                                            │
│  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌─────────┐ │
│  │ 力传感器  │──▶│ PI 力控制 │──▶│ 导纳滤波器│──▶│ FOC速度环│ │
│  │ I2C/SPI  │   │ Kp+Ki/s  │   │1/(M·s+B) │   │   PI     │ │
│  └──────────┘   └──────────┘   └──────────┘   └────┬────┘ │
│                                                     │      │
│                                          ┌──────────▼────┐ │
│                                          │  FOC 电流环    │ │
│                                          │  PI → SVPWM   │ │
│                                          └───────┬───────┘ │
└──────────────────────────────────────────────────┼────────┘
                                                   │
                                              ┌────▼────┐
                                              │ 无刷电机  │
                                              │ 减速器    │
                                              │ 助力轮    │
                                              └─────────┘
```

### 3.2 各层职责

| 层级 | 频率 | 功能 |
|---|---|---|
| **PI 力环** | 200 Hz | 保证 $F_{sensor} \to 0$（消除稳态误差） |
| **导纳滤波器** | 200 Hz | 塑造手感：力→速度的映射（$M_d$, $B_d$） |
| **FOC 速度环** | 1 kHz | 速度跟踪，提供底层阻尼 |
| **FOC 电流环** | 16 kHz | 电流/转矩控制 |

### 3.3 为什么需要 PI + 导纳

**纯导纳控制的问题：**

纯导纳 $v_{des} = \dfrac{F_{sensor}}{M_d s + B_d}$ 在稳态时存在非零误差：

$$\lim_{t \to \infty} F_{sensor} = F_{human} \cdot \frac{B_d}{B_d + K_{sys}}$$

其中 $K_{sys}$ 是速度指令到助力的稳态增益。除非 $B_d \to 0$（会导致不稳定），否则无法实现零稳态力。

**解决方案：** 在导纳层前加 PI 控制器。PI 的积分项累积力误差，持续调整速度指令直到 $F_{sensor} = 0$。

**串联传函：**

$$C(s) = \frac{V_{des}(s)}{F_{sensor}(s)} = \left(K_p + \frac{K_i}{s}\right) \cdot \frac{1}{M_d s + B_d} = \frac{K_p s + K_i}{s (M_d s + B_d)} \tag{2}$$

## 4. 数学推导

### 4.1 被控对象建模

FOC 速度闭环 + 电机 + 减速器 + 助力轮等效为一阶系统：

$$G(s) = \frac{F_{motor}(s)}{V_{des}(s)} = \frac{K_{sys}}{\tau_{sys} s + 1} \tag{3}$$

| 参数 | 含义 | 获取方式 |
|---|---|---|
| $K_{sys}$ | 速度指令→助力增益 (N/(rad/s)) | 阶跃速度测试，$K_{sys} = F_{ss} / V_{cmd}$ |
| $\tau_{sys}$ | 速度环等效时间常数 (s) | 阶跃响应 10%→90% 上升时间，$\tau \approx T_r / 2.2$ |

### 4.2 开环传递函数

$$L(s) = C(s) \cdot G(s) = \frac{K_{sys} (K_p s + K_i)}{s (M_d s + B_d) (\tau_{sys} s + 1)} \tag{4}$$

开环系统为 **I 型**（原点处有一个极点），因此对阶跃输入的稳态误差为零。

### 4.3 闭环传递函数

力传感器读数对用户推力的响应：

$$\frac{F_{sensor}(s)}{F_{human}(s)} = \frac{1}{1 + L(s)} = \frac{s (M_d s + B_d) (\tau_{sys} s + 1)}{s (M_d s + B_d) (\tau_{sys} s + 1) + K_{sys} (K_p s + K_i)} \tag{5}$$

### 4.4 特征方程

$$M_d \tau_{sys} \cdot s^3 + (M_d + B_d \tau_{sys}) \cdot s^2 + (B_d + K_{sys} K_p) \cdot s + K_{sys} K_i = 0 \tag{6}$$

令：
- $a_3 = M_d \tau_{sys}$
- $a_2 = M_d + B_d \tau_{sys}$
- $a_1 = B_d + K_{sys} K_p$
- $a_0 = K_{sys} K_i$

### 4.5 稳态分析

| 输入信号 | 稳态误差 |
|---|---|
| 阶跃 $F_{human}(t) = F_0 \cdot u(t)$ | $F_{sensor}(\infty) = 0$ （PI 的 I 项保证） |
| 斜坡 $F_{human}(t) = r \cdot t$ | $F_{sensor}(\infty) = \dfrac{B_d \cdot r}{K_{sys} K_i}$ |

## 5. 离散实现

### 5.1 控制周期

$\Delta T = 5\text{ ms}$（200 Hz），在定时器中断中执行。

### 5.2 算法流程

```
Step 1.  I2C/SPI 读取力传感器原始值 → F_raw

Step 2.  低通滤波 (一阶 IIR)
          α = 2π·fc·ΔT / (2π·fc·ΔT + 1)
          F_filt = α · F_raw + (1 - α) · F_filt_prev

Step 3.  死区判断
          if |F_filt| < dead_zone:  F = 0
          else:                      F = F_filt

Step 4.  误差计算
          e = F    (setpoint = 0)

Step 5.  积分累加 (前向欧拉)
          I = I_prev + e · ΔT

Step 6.  PI 输出
          F_virtual = Kp · e + Ki · I

Step 7.  导纳滤波器 (前向欧拉)
          a_des = (F_virtual - B_d · v_des) / M_d
          v_des = v_des + a_des · ΔT

Step 8.  速度限幅
          v_des = CLAMP(v_des, -V_MAX, +V_MAX)

Step 9.  PI 抗饱和 (条件积分)
          if v_des >= V_MAX and e > 0:   I = I_prev
          if v_des <= -V_MAX and e < 0:  I = I_prev

Step 10. 写入 FOC 速度环 setpoint
          foc_speed_setpoint = v_des
```

### 5.3 C 语言参考实现

```c
// ============================================
// 导纳控制 —— MCU 定时器中断 (5ms)
// ============================================

#include <math.h>

/* ====== 可调参数 ====== */
#define DT          0.005f    // 控制周期 (s)
#define KP          3.0f      // PI 比例增益
#define KI          6.0f      // PI 积分增益
#define MD          0.5f      // 虚拟质量 (kg)
#define BD          1.0f      // 虚拟阻尼 (N·s/m)
#define DEAD_ZONE   0.15f     // 死区 (N)
#define FILT_FC     20.0f     // 低通截止频率 (Hz)
#define V_MAX       300.0f    // 最大速度指令 (rad/s)

/* ====== 滤波器系数 (预计算) ====== */
#define ALPHA  (2.0f * 3.14159f * FILT_FC * DT /  \
               (2.0f * 3.14159f * FILT_FC * DT + 1.0f))

/* ====== 状态变量 ====== */
static float v_des  = 0.0f;   // 期望速度 (输出给FOC)
static float F_filt = 0.0f;   // 滤波后的力
static float integral = 0.0f; // PI 积分项

/**
 * @brief 导纳控制步进函数, 每个控制周期调用一次
 * @param F_raw  力传感器原始读数 (N), 前推为正
 * @return       速度指令 (rad/s), 写入 FOC 速度环 setpoint
 */
float admittance_control_step(float F_raw)
{
    /* 1. 低通滤波 */
    F_filt = ALPHA * F_raw + (1.0f - ALPHA) * F_filt;

    /* 2. 死区 */
    float F = (fabsf(F_filt) < DEAD_ZONE) ? 0.0f : F_filt;

    /* 3. 误差 */
    float error = F;

    /* 4. PI: F_virtual = Kp*e + Ki*∫e dt */
    float I_new = integral + error * DT;
    float F_virtual = KP * error + KI * I_new;

    /* 5. 导纳: a = (F_virtual - B*v) / M */
    float a_des = (F_virtual - BD * v_des) / MD;

    /* 6. 欧拉积分: v += a*dt */
    float v_new = v_des + a_des * DT;

    /* 7. 速度限幅 + 抗饱和 */
    if (v_new > V_MAX) {
        v_new = V_MAX;
        /* 条件积分: 已达上限且误差仍为正向, 冻结积分 */
        if (error > 0.0f) { I_new = integral; }
    } else if (v_new < -V_MAX) {
        v_new = -V_MAX;
        if (error < 0.0f) { I_new = integral; }
    }

    /* 8. 更新状态 */
    v_des    = v_new;
    integral = I_new;

    return v_des;
}

/**
 * @brief 停止时重置导纳控制器状态
 */
void admittance_control_reset(void)
{
    v_des    = 0.0f;
    F_filt   = 0.0f;
    integral = 0.0f;
}
```

### 5.4 导纳滤波器离散化的数值稳定性

使用前向欧拉法离散化导纳方程 $M_d \dot{v} + B_d v = F_{virtual}$：

$$v[k] = v[k-1] + \frac{F_{virtual}[k] - B_d \cdot v[k-1]}{M_d} \cdot \Delta T$$

**稳定性条件：** $\Delta T < \dfrac{2 M_d}{B_d}$

以 $M_d = 0.5$、$B_d = 1.0$ 为例：$\Delta T_{max} = 1.0\text{ s}$，远大于 5 ms，数值稳定。

## 6. 参数整定

### 6.1 整定步骤

| 步骤 | 操作 | 判断标准 |
|---|---|---|
| **1. 系统辨识** | 给固定速度指令，测量稳态助力 | 得到 $K_{sys}$ 和 $\tau_{sys}$ |
| **2. 定 M_d, B_d** | 先设 $M_d=0.5$, $B_d=1.0$ 作为起点 | — |
| **3. 调 Kp** | $K_i=0$，逐步增大 $K_p$ | 推拉时力传感器有明显响应，不振荡 |
| **4. 调 Ki** | 固定 Kp，逐步增大 Ki | 推住不动时传感器读数缓慢归零 |
| **5. 调 M_d** | 快速推拉，感受跟手程度 | 无延迟感 = OK，延迟大 → 减小 $M_d$ |
| **6. 调 B_d** | 匀速推拉，感受阻力 | 阻力大 → 减小 $B_d$，太飘 → 增大 $B_d$ |
| **7. 调死区** | 手离开设备 | 电机完全静止，无抖动 |

### 6.2 参数物理含义

| 参数 | 物理类比 | 增大效果 | 减小效果 |
|---|---|---|---|
| $K_p$ | 力→速度的"弹性系数" | 响应更快，可能振荡 | 响应慢，更稳 |
| $K_i$ | 消除残余力的"耐心" | 归零更快，可能过冲 | 归零慢，但平稳 |
| $M_d$ | 设备的"虚拟重量" | 启动慢，速度平滑 | 跟手，但可能不平顺 |
| $B_d$ | 设备的"虚拟摩擦" | 阻力感强，速度稳 | 省力，可能太飘 |

### 6.3 常见问题与解决

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 静止时电机抖动 | 传感器噪声或死区太小 | 增大死区 / 降低滤波截止频率 |
| 推起来费力 | $B_d$ 太大 | 减小 $B_d$ |
| 推拉感觉"延迟" | $M_d$ 太大 | 减小 $M_d$ |
| 速度变化太猛 | $M_d$ 太小 | 增大 $M_d$ |
| 松手后设备滑太远 | $B_d$ 太小 | 增大 $B_d$（增加虚拟摩擦） |
| 传感器不归零 | $K_i$ 太小 | 增大 $K_i$ |
| 传感器归零但振荡 | $K_p$ 太大 或 $K_i$ 太大 | 减小增益 |

## 8. 与 FOC 的集成

### 8.1 架构关系

导纳控制器和 FOC 运行在同一颗 AT32 MCU 上：

```
定时器中断 (5ms, 优先级低):
  ├── I2C/SPI 读取力传感器
  ├── admittance_control_step(F_raw)
  └── 写入 g_speed_setpoint = v_des

FOC 电流环中断 (62.5μs, 优先级高):
  ├── 读取相电流 ADC
  ├── Clarke/Park 变换
  ├── 电流环 PI (setpoint: Iq_ref)
  └── SVPWM 输出

FOC 速度环 (1ms, 在电流环中断内计数):
  └── 速度环 PI (setpoint: g_speed_setpoint)
```

### 8.2 接口约定

导纳控制器和 FOC 之间通过一个全局变量交换数据：

```c
volatile float g_speed_setpoint = 0.0f;  // rad/s, 电气角速度
```

- 导纳控制器（5ms 中断）：写入 `g_speed_setpoint`
- FOC 速度环（1ms）：读取 `g_speed_setpoint` 作为速度环 setpoint

## 9. 传感器信号调理

### 9.1 低通滤波器设计

- **类型：** 一阶 IIR 低通
- **截止频率：** $f_c = 20\text{ Hz}$（可根据传感器噪声水平调整）
- **系数：** $\alpha = \dfrac{2\pi f_c \Delta T}{2\pi f_c \Delta T + 1}$

| $f_c$ | $\Delta T = 5\text{ ms}$ 时的 $\alpha$ | 适用场景 |
|---|---|---|
| 10 Hz | 0.239 | 传感器噪声大 |
| 20 Hz | 0.386 | 通用 |
| 50 Hz | 0.611 | 传感器噪声小，需要快速响应 |

### 9.2 死区标定方法

1. 设备静止，手不接触手柄
2. 连续读取 1000 个传感器样本（约 5 秒）
3. 计算标准差 $\sigma$
4. 死区 = $3\sigma$（覆盖 99.7% 的噪声）
5. 如传感器噪声 $\sigma = 0.03\text{ N}$，则死区 = 0.09 N，向上取整为 0.1 N

## 10. 系统辨识方法

### 10.1 辨识 $K_{sys}$

1. 禁用导纳控制器，直接给 FOC 发送固定速度指令 $V_{cmd}$
2. 测量稳态时产生的助力 $F_{ss}$（通过力传感器或外部分析）
3. $K_{sys} = F_{ss} / V_{cmd}$
4. 测量多组取平均值

### 10.2 辨识 $\tau_{sys}$

1. 给阶跃速度指令 $V_{cmd}$（从 0 跳到 $V_0$）
2. 记录助力响应曲线 $F_{motor}(t)$
3. 找到 $F_{motor}$ 从稳态值 10% 上升到 90% 的时间 $T_r$
4. $\tau_{sys} \approx T_r / 2.2$（一阶系统近似）

## 11. 总结

### 核心公式速查

| 公式 | 说明 |
|---|---|
| $F_{sensor} = F_{human} - F_{motor}$ | 物理模型 |
| $C(s) = \dfrac{K_p s + K_i}{s (M_d s + B_d)}$ | PI + 导纳控制器传函 |
| $G(s) = \dfrac{K_{sys}}{\tau_{sys} s + 1}$ | 被控对象传函 |
| $a_3 s^3 + a_2 s^2 + a_1 s + a_0 = 0$ | 闭环特征方程 |
| $F_{sensor}(\infty) = 0$ (阶跃) | 稳态特性 |
